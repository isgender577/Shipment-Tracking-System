# Shipment Tracking System

A Java-based application developed using Eclipse IDE to manage shipment operations and track deliveries. The system includes separate admin and customer roles, shipment tracking functionality, and support for enclosed and open-carrier shipments. It applies Object-Oriented Programming (OOP) principles, interfaces, and file handling to organize shipment records and manage user sessions.

## Features

* Role selection and user login
* Admin and customer management
* Shipment tracking functionality
* Support for enclosed and open-carrier shipments
* User session management
* File-based data storage and retrieval

## Technologies

* Java
* Object-Oriented Programming (OOP)
* Interfaces
* File Handling
* Eclipse IDE
